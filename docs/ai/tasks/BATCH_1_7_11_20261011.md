## Implemented requirements

- Only Patrol/Stay are selectable, mutually exclusive, free and server-authoritative. Default Patrol retains native follow/defensive target goals; incoming-damage evidence prevents proactive targets. Existing native fights continue without re-scanning.
- Stay recalls through loaded native navigation until within five blocks, then records each wolf's fixed position. Repeated selected clicks are no-ops. No forced chunk loads or teleport recall.
- Clears targets, anger and wolf/owner-goal combat memory on transitions. Stay rejects new targets and does not collect threats; returning Patrol cannot resume previous fights. Owner combat state itself remains intact.
- Epochs distinguish Stay/Patrol/Stay while a wolf is unloaded. Ordinary reloads preserve settled anchors; unavailable owners pause uncompleted recall.
- Old paid Breed/Summon/Regroup/Heal and six mode requests are denied server-side. Kibble regeneration/recycling and UI disappear. Pending command journals still reconcile without replay/refunds.
- Existing eggs/taming/breeding, unlimited player pack lifecycle and allied protection remain. Mercenary wolves are excluded from this mode manager.
- Help content reflects two live modes. No authored chest/item, server configuration or local client changes.
