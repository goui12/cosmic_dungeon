# FixSet F1 — shared inventory and potion list
Scope approved October13: F1 only. Six-batch queue; Alpha after F2/F4, Beta after F6. This explicit milestone policy supersedes routine per-batch publication for this fix set.

## Changes and cause
The installed ClientPacketListener replaces LocalPlayer on respawn/dimension travel. The prior class listener only requested class data on login, so inventory theme/potion eligibility/Bogatyr providers could lose class identity. Request existing server class sync on the native post-replacement Clone event. No new payload or NBT schema.
The old Craft toggle and I/II/+ family selectors are replaced by an always-visible opaque right-hand list. All server legal variants are independently shown. The client reuses the vanilla catalog once per feature set/connection for disabled previews; actual run/revision quotes remain the sole purchase authority. Only visible rows have hit boxes; wheel/track/drag scroll is bounded. Existing cached server quotes and serialized crafting custody remain unchanged.
Review also fixed two P2 regressions: the list is included in native outside-drop bounds, and brewer effect icons use the former Craft space above Resurrect with complete overflow tooltips. This preserves carried-item cleanup and effect information that the right panel would otherwise cover.
Creative remains native fallback; normal and Extra inventory slots are not moved. Retired Requests rendering is not registered, so its former right-hand reservation is unused.

## Validation and limits
Java21 build/tests and relevant source JSON/diff checks are required. CI clean build/native GameTests and actual diff review are required before completion. Exact source/run IDs and counts live in the FixSet controller completion receipt, not speculative pre-build claims.
New tests verify installed native clone ordering and single existing sync request, every variant, preview denial, one in-flight craft, exact acknowledgements, bounded scrollbar and reachability of all96 potential rows at supported GUI sizes. New native outside-drop hook checks and compact-effect geometry checks cover the review corrections. Prior crafting/recovery/fuel/native tests remain required.
No datagen, save migration, runtime dependency or heap/worker increase. One bounded cached vanilla recipe graph per connection; unavailable quotes retry at most once per second while the panel is actually open. No per-frame recipe or inventory scans. Existing local catalog fixtures measured 6–21 ms per catalog/assertion case; these are unit timings, not in-game frame measurements.
