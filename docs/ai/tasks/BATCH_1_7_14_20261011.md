# Batch14: Spawner editor foundation — 1.7.14-alpha.1
Approved scope: [series plan](ALPHA_1_7_BATCH_PLAN_20261010.md), card14 and the approved spawner GUI specification. Stop after14.

## Implemented
- Developer-only /spawner edit opens the looked-at Cosmic Spawner within5 blocks. Four icon sections provide searchable entity selection, name/captain, boss/cap/delay, five generic flags and rotating visual preview.
- Detached drafts retain partial input across tabs/resizes. Apply validates fresh rank, target identity, distance, live configuration and session ownership; concurrent changes reject the stale editor. Cancel/confirmed discard never applies input. Preview mobs are cached client objects, never world-added or ticked; logout releases preview/world references.
- Silent, NoAI, Invulnerable, Persistent and AlwaysShowName apply to native spawned/maintained mobs. Explicit name clearing survives weighted entries; captain and persistence are independent.
- Intrinsic Developer hover replaces /spawner showlabels. Public block updates contain visual identity and blocked status only; private details require a fresh Developer check and looked-at target. Dungeoneers receive no detailed hover response.
- Wrong-tool warnings require20 uninterrupted native breaking ticks, reset on release/retarget/tool change, and warn once per hold. Single combat taps do not warn.
- Right-click equipment copying and existing commands remain. New metadata-only presets do not claim authored equipment/drop chances/intrinsic loot. Weighted spawn potentials, untouched native limits, rich names, boss progress and unknown root/preset/rule fields are covered by preservation regressions.

## Compatibility and cost
Protocol30 ->31; update both sides together. Block entity152 ->153; preset4 ->5. Additive override fields default to legacy behavior for existing presets. Existing/unloaded saves migrate lazily through their normal load/save, without world scans or authored-chest changes; native old-shape tests retain registry IDs and representative authored NBT. Named preset files embed this additive preset payload; full native preset export remains Batch16.
Newer schema versions remain intact and are rejected by the editor. Names over128 characters and snapshots over64KiB of textual NBT are read-only in this editor. Back up a world before upgrading; older binaries do not understand these override fields, so restore the prior backup for rollback.
One expiring draft per Developer, one inspected hover cache, at most two hover requests/second; no global entity/inventory/chunk scans or new runtime dependencies. Breaking checks exit immediately for players not breaking a block. A preview allocates once per changed entity, never per frame.
