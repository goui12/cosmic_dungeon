Distance within the run does not matter. Stale group/run context cannot change consent; sender identity controls whose choice changes.

## Save compatibility and recovery
Additive resource_sharing_v1:<UUID> values use the existing cosmicdungeon_d1_objectives_v1 per-run unique map. No schema/version/key migration is needed. Old saves and absent, malformed/multiple or unknown future choices fail closed as UNKNOWN; loading never rewrites unknown values or unrelated fields. Explicit new choices replace only that member's key.
Normal SavedData persistence retains active-run choices across restart. If a crash precedes a durable choice/entry handoff save, UNKNOWN prompts again and never becomes hidden YES. Run retirement uses existing clearRun.
Rollback preserves the existing-format values but older builds do not expose the new consent UI/helper; no new shared-crafting feature has been enabled in this batch.
