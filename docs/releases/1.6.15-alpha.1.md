# Cosmic Dungeon 1.6.15-alpha.1

- Bogatyr Wolfpack now offers all six free, server-authoritative modes.
- Strategic prioritizes ranged enemies, then enemies with the most maximum health.
- Search and Rescue protects nearby party players at3 hearts or less, moves between them and actual attackers, and redirects attackers.
- Companionship restores1 heart every5 seconds per guarded player; extra wolves do not multiply healing.
- Danger Close keeps paths within16 blocks of the moving master, finishes an eligible current target, then prioritizes threats to the master.
- Shared target searches and staggered path work support large packs without a new wolf cap. Friendly players, pets and NPCs remain protected.
- Existing saved mode selections and unknown save fields are preserved. The unrelated Potion of Companionship remains unchanged.

Set C Alpha. Licensed visual/co-op/pathfinding acceptance remains TESTING. Install the matching runtime/loading companion through CurseForge; TEST delivery uses stopped-server sFTP.
