# 1.7.1 Alpha 2
- Inventory item, skill, group, currency and other screen tooltips render after overlays, so panels no longer cover them.
- Hover an active dungeon party member to see current-run details. Long details still have an optional click-to-expand view; individual effect icons retain their own hover descriptions.
- Hover inspection stops on close, dragging, target/run changes or loss of access. Requests are throttled and stale replies discarded; server membership checks remain authoritative.
- Native wolf projectile and potion tests now use discoverable targets in the loaded structure chunk. Flaming-arrow tests use a temporary rain shelter, preserving allied protection, hostile damage and beneficial effects.
- No save migration or gameplay balance change.

Testing: GUI scale/readability, modal layering and licensed multiplayer acceptance remain pending TESTING. This is Batch 1 of the new 1.7 series; the remaining inventory, resource, potion, wolf-mode, spawner and help redesigns are planned for later batches.

Release candidate1 failed native spawner fixture checks before any upload. Candidate2 corrects the test chunk anchor and preserves exact XP-bottle loot/protection assertions; production spawner behavior is unchanged.
