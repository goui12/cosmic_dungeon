# 1.8.3-alpha.1
Potion palette tooltips now explain the exact affordable server-selected route for one output, its consumed starting potion, remaining ingredients and own/eligible-group quantities. Ingredient powder and fuel powder share one debit total; the fuel line explains the refill portion and saved charges. Unavailable and pending snapshots state their limits and reserve nothing.

The existing cached quote, vanilla route legality and server transaction revalidation are retained. Network protocol34 requires matching client/server builds; worlds, NBT and custody schemas are unchanged. No save migration is required; rollback retains the existing save format but clients and servers must use the same protocol.

Java21 local, full clean/native CI and publisher GameTests are required. Native visual acceptance remains TESTING. Alpha publishes runtime and matching loading companion; TEST delivery is not required.
