# Cosmic Dungeon 1.7.16-alpha.1
Batch16 completes the Developer spawner editor's drops and preset library.

- Edit equipment drop chances, inspect native loot, and add separate override or independent custom item/count/chance rules.
- Native conditional loot is labeled honestly; duplicate custom item rows roll independently.
- Browse, save, load, overwrite and delete named presets; assign or clear the existing five shortcuts.
- Save and Load stay in the draft workflow. Main Apply changes the spawner; Cancel discards a loaded draft.
- Full typed preset exports preserve equipment, weighted spawning, flags and unknown data; old preset files remain compatible.

Open with Developer /spawner edit, then Drops / files. Matching client/server builds are required (protocol33). Back up worlds and preset files before upgrading. Block data154, preset5, file export4; no bulk world migration.
Automated gates and exact release evidence are in the Batch16 controller receipt. Licensed GUI/multiplayer acceptance remains TESTING.
Alpha publication includes the runtime and matching companion on CurseForge. No server or local-client installation is performed for this Alpha.
