Unpublished Batch 1 source beta. Local development source and GitHub are updated; this revision is not installed on TEST or the local client and is not uploaded to CurseForge. The official build is reserved for completion of Batch 6.

All new generic slots remain unassigned in this batch. Positive Potions retains and extends existing useful-support XP; other new player action hooks are scheduled with the ability batches. Protocol 36 requires matching client/server code when the completed series is installed.
