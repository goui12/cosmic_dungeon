# Cosmic Dungeon 1.8.13

Official release of the six-batch class-skills set, authorized by Cameron after automated completed-set validation.

- Shared player/mercenary signature identities and class-independent G/Z/X/C bindings; actual-key labels and disabled unassigned slots.
- Theurgist max-health ranks from Scintilla Vitalis to Fulgor Vitae, strongest-only 45-minute base-health bonuses and level25 potion cadence improvements.
- Charged Dragoon Chain Lightning and undead-only Judicator Smite, with independent charge/proficiency and useful automatic mercenary use.
- Five-minute party buffs: Flurry of Fangs, Blackiron Sheath, Judicator’s Aegis/Defender’s Bulwark, and Banish Afflictions.
- Independent mercenary spawner and stationary-healing protections with private warnings and active-participation recovery.
- Yellow party class labels, blue abbreviated levels, visible charge/cooldown bars, and colored effect name/amount/caster/duration details.
- Player Negative Potions, Wolves and Fireworks earn from actual successful actions with per-action/identity deduplication.

Network protocol39 requires matching runtime versions. Existing player/run skill stores, authored chests, spawner IDs and unknown fields are preserved. Effect caster metadata is additive; historical unknown casters stay Unknown. No world/spawner migration or replacement is required. Legacy effects and pending player poison ticks restored from old saves do not invent new skill credit.

Runtime and optional client-only loading-screen companion are published together. Only the runtime belongs on TEST. Clients update through CurseForge. No game/server launch or local client installation is part of this release. Actual licensed rendering/co-op acceptance remains TESTING; automated tests are reported separately.
