# Cosmic Dungeon 1.8.8-beta.1

Completed FixSet F1-F6 Beta candidate for Minecraft1.21.10 / NeoForge.

- Shared class inventory widgets survive dungeon lifecycle changes. Theurgist and Venefex use one opaque scrollable list of all legal normal/strong/extended potion variants. Bogatyr Patrol, Stay and Feed Pack actions are restored.
- The Ready action uses a restrained green pulse. Contribution choices freeze when adventure start is accepted and unlock after return to pre-game.
- Legitimate player wolf packs remain unlimited. Duplicate admissions are rejected; hired Bogatyrs have a20-dog admission cap and30-second starting summons. Patrol defends and assists the master's attacks. Bounded wolf diagnostics capture the next spawning incident.
- Spawner upgrades occur in development worlds as chunks load; authentic messages remain. Developers explicitly save dungeon_1 afterward. Startup phase timing identifies work without claiming a whole-world speedup.
- New mercenaries use80 short names divided evenly across eight regional pools; existing hires keep their identities.
- Renamed vanilla fireworks load into bows and crossbows with their components/effects preserved. Rebindable R cycles eligible ammunition, switches automatically on depletion and reports the current key or empty stock. Charged crossbows keep their load.
- Ordinary weapon use passes through spawners; deliberate Developer Shift+right-click copies equipment. Skeleton bow equipment and native ranged behavior are preserved.
- Conditional loot smelting produces the native result without unlocking player, furnace or crafter production.
- All45 supported hostile mob types have default Trace registrations. The18 approved additions include zombie villagers at3 and shulkers at4 before group splitting. Configured category amounts and explicit entity/spawner overrides retain precedence; no retroactive reward.

## Configuration compatibility

A nonempty saved registeredMobRewards table receives only the18 newly approved types
when absent. Explicit entries, including0 and invalid/duplicate entries, never fall
back; invalid entries fail closed. Set a new type to0 to disable it. An empty table
continues to disable type defaults. Original registrations removed by an administrator
remain removed. No saved config, world, chest stack or schema is rewritten.

Runtime and matching client-only loading-screen companion publish together from the
validated main merge. Only the runtime is delivered to freshly confirmed stopped TEST.
Clients update through CurseForge; no local client/helper installation or server restart.
Exact source/build/review/publication/deployment evidence is recorded in the F6 receipt.
Licensed GUI, multiplayer, authored-world, rocket effects and real wolf-incident
acceptance remain TESTING; this Beta is not a stable gameplay-acceptance claim.
