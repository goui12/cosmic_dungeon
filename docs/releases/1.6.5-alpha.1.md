# Cosmic Dungeon 1.6.5-alpha.1

Batch15 adds current-run human member inspection from the inventory party roster. View name/class, live health and effects, existing ability and item cooldowns, ore where applicable, run kills, hostile damage dealt, healing received and deaths. Details refresh only while open, with wheel and draggable-scrollbar access.

Server checks active run membership for both viewer and subject. Protocol19 requires matching client/server runtime versions. Offline/outside-run members have no stale live health or ability readings.

New event counters begin at zero for existing runs and persist in the existing extensible run store until run retirement. They do not reconstruct activity before this update or use lifetime statistics. No new registry IDs, spawner formats or world schema migration. Brewing Supplies/Kibble remain scheduled for Batch20.

Automated build, native CI and release evidence must pass before distribution. Licensed GUI, co-op and CurseForge companion-app delivery acceptance remains pending. Alpha release; completed SetA Beta follows Batch16.
