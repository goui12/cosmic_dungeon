# 1.8.10-beta.1 — class skills Batch 2

Unpublished source beta for the six-batch class-skills update. Local development and GitHub only; TEST, local client and CurseForge delivery remain held until Batch 6.

Theurgist players and mercenaries share ten max-health potion ranks: +10% at level0 through +55% at68. Each lasts45 minutes, uses base health, never heals, and rejects equal/weaker refreshes. The player palette offers only the highest unlocked rank, using standard Splash Healing ingredients and fuel. Old physical bottles remain intact.

Mercenary Theurgists now use Healing and max health only. Positive potion quality/cooldown bonuses begin at25. Player beneficial recipes and resurrection retain their existing scope. Rank unlocks broadcast within the dungeon instance.
