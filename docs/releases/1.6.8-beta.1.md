# Cosmic Dungeon 1.6.8-beta.1

Set B Beta: mercenary potion roles and Judicator Combat.

- Theurgist mercenaries use positive potions; Venefex use negative potions and start at level0.
- Judicator Combat starts at0 and advances at1,3,6,12,24 total hostile kills, then doubling.
- Successful direct attacks can cause a two-block hostile-only burst: L% chance, L HP damage,
  with probability capped at100%. Secondary burst damage cannot trigger another burst.
- Preserve allies, run progression through death/revival and reset progress for a new dungeon.
- Preserve authored class-chest equipment and existing saved identities/counters.

This is a testing Beta. Licensed multiplayer/HUD/gameplay and CurseForge app acceptance
remain pending. Clients update through CurseForge; only TEST receives the direct sFTP update.
