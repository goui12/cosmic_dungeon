# Cosmic Dungeon 1.6.16-beta.1

Set C Beta brings together the inventory Skills panel, class resources, group supply
requests, player Theurgist actions and run-only Bogatyr Wolfpacks.

- Move, minimize and reset the per-class Skills panel. Scroll long action lists with the wheel or visible scrollbar; Requests remain independently accessible.
- Theurgists use Brewing Supplies and Bogatyrs use Kibble: start at0 each dungeon, regenerate1/second online and cap at600. Recycle only eligible tagged items, preserving items beyond available capacity.
- Group supply requests require explicit donor consent, preview exact items/yield, and recheck inventory, class, run and resource capacity at execution.
- Theurgists craft normal/epic positive splash potions for20/40 supplies and offer resurrection for120, charged only after successful acceptance. New deaths replace old offers; player resurrection has no mercenary cooldown.
- Bogatyrs can Breed, Summon, Regroup and Heal their current-run pack. Exact affected counts/costs are previewed; failed or ineligible actions cost nothing.
- All six free wolf modes are available: Defensive, Stand Ground, Aggressive, Strategic, Search and Rescue, and Danger Close. Companionship heals once per guarded player; Danger Close follows the moving16-block master boundary.
- Packs end with the dungeon and retain normal active-run save/reconnect behavior. Existing saves, unknown fields and authored chest/loadout/spawner data remain preserved.
- Integration regressions cover combined panel/input behavior, crafting versus supply consent/caps, resurrection versus resource spending/latest death, and pack mode changes/friendly protection/retirement.
- Corrected the breeding tooltip: switch out of Stand Ground; every other mode permits eligible breeding.

This is a testing Beta. Licensed GUI rendering, sustained terrain/co-op gameplay and
CurseForge app acceptance remain TESTING. Stable promotion requires that gameplay
acceptance. Clients update through CurseForge; TEST receives only the runtime via
stopped-server sFTP.
