# Cosmic Dungeon 1.5.2 Beta 1

Public beta for Minecraft **1.21.10**, **NeoForge 21.10.64**, and **Java 21**.
Install the same Cosmic Dungeon version on the client and server. This is a beta;
multiplayer gameplay acceptance is ongoing.

## Included in this beta

- Dungeon group readiness, Tamsin's adventure interface, instance difficulty,
  slot-owned class chests, death/forfeit handling, and inventory restoration work.
- Class weapon and potion skill progression, dungeon currency/trade interfaces,
  lore advancement presentation, lifetime statistics, and eight curated leaderboards.
- Hired mercenaries with group HUD support, following/combat, retained equipment on
  death, and useful container-loot copies that preserve the original player loot.
- Theurgist mercenaries handle potion use and instant brewing from their own supplies
  at accessible nearby brewing stands. Other classes retain shared follow/combat AI.
- Bogatyr mercenaries summon one allied dog every two minutes, up to five, with
  protection from allied attacks and harmful potion effects.
- Fixes for Tamsin text input, mercenary pickup crashes, and friendly-fire handling.
- Custom menu artwork, music, panorama, and the separately packaged loading theme.

## Installation and loading screen

The main mod JAR is the normal CurseForge installation for clients and servers.
The matching `-loading-screen.jar` is an optional **client-only startup component**.
The additional-file copy on CurseForge is an archive for manual installation;
CurseForge does not install additional files automatically. Existing configured
clients can replace their old helper with the matching helper while Minecraft is closed.
The helper now contains and refreshes its own matching theme assets. New clients need
two FML settings enabled once; see the repository's
`docs/CURSEFORGE_RELEASES.md`. A dedicated companion project is needed for app-managed
helper updates. Do not install this startup helper on the server.

The mod provides dungeon systems; this upload does not bundle the development
server's world, authored dungeon map, account data, or private configuration.

The new mercenary names/skins, paid instant revival, mercenary skill leveling,
advanced Pyroclast/Dragoon AI, and level-50 Theurgist resurrection are planned for
subsequent batches and are **not included in this beta**.
