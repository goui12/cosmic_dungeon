# Cosmic Dungeon 1.6.10-alpha.1

- Add Brewing Supplies for Theurgists and Kibble for Bogatyrs. Each starts at0 in a
  new dungeon run and grows1 per second while online, up to600. Balances survive
  death and reconnecting; offline time adds nothing.
- Recycle eligible supplies from your inventory into your class resource. Each item
  grants1 resource; only the space remaining below600 is consumed.
- Add shaded herb/Kibble bars above the world HUD and in Skills. Minimized Skills
  keeps the count visible, and resource/action tooltips use the requested styling.
- List convertible supplies in the H class guide directly from server item tags.

Testing Alpha: licensed visual, multiplayer and CurseForge app acceptance are pending.
Request Supplies remains unavailable until the group-request feature is delivered.
Clients update through CurseForge; TEST receives the direct sFTP runtime update.
