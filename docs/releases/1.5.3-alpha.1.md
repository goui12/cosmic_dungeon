# Cosmic Dungeon 1.5.3-alpha.1

- Group leaders stay in Tamsin's menu after pressing Ready, with Start Adventure available once everyone is ready.
- Mercenaries receive one of 100 short English-inspired names and one of nine built-in player skins.
- Each hire keeps its name and appearance across dungeon entry, death, revival and reload.
- Mercenary Group HUD labels show their names without an owner or Mercenary prefix.

Requires Minecraft 1.21.10, NeoForge 21.10.64 and Java 21. Use the matching
1.5.3-alpha.1 loading-screen companion on clients. This is a testing alpha;
multiplayer interaction and visual acceptance remain part of gameplay testing.
No save-format changes or manual world migration are required.
