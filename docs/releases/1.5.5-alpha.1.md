# Cosmic Dungeon 1.5.5-alpha.1

Batch 3: mercenary recovery and payments.

- New default hire price: 50 Trace. Revive a dead hire from inventory for half its frozen hire price (25 Trace for a new default hire).
- If you cannot afford a revival, choose Yes to ask your group. A clickable chat request lets one member cover the full revival; duplicate or stale clicks cannot charge again.
- Paid recovery bypasses the ten-minute countdown and returns the original companion, equipment and supplies beside its hirer when a safe location is available.
- After 15 seconds without combat, active companions regenerate 0.5 health points per second, up to full health.

Update the server and client together (network protocol 14). The matching loading-screen JAR remains client-only.
Existing hired contracts retain their recorded price; custom config overrides remain supported. Rest records add an optional death UUID to reject stale same-tick revivals. Old records load with a stable legacy default and resave automatically; no manual world or spawner migration is required.
Manual multiplayer and GUI acceptance remains pending.
