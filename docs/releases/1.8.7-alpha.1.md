# Cosmic Dungeon 1.8.7-alpha.1

Second FixSet Alpha milestone, F3/F4, Minecraft 1.21.10 / NeoForge.

- Copied/conflicting player wolf bonds are rejected before insertion. Player packs
  remain uncapped through legitimate eggs, taming and breeding.
- Hired Bogatyrs admit at most 20 dogs, start at 30-second summons, retain approved
  skill cadence progression and avoid repeated-callback/offline catch-up bursts.
- Patrol assists successful master attacks against eligible hostiles and still
  defends its master; Stay and allied protection remain authoritative.
- Server wolf incident logs are enabled with bounded counters/samples, separating
  attempts, real additions, disk loads, eggs, births, summons, rejection and removal.
- Spawner upgrades happen in development worlds as chunks naturally load.
  Authentic upgrade messages remain. Instances read older snapshots compatibly.
  Developers must explicitly /world save dungeon_1 after changing/upgrading the
  required development chunks; no automatic snapshot save or forced chunk load.
- Startup phase timings and operation counts expose copying, chunk/world work,
  schematics, migrations, admissions and teleports. No whole-world speedup or
  cause of the earlier lag/wolf incident is claimed.
- New mercenaries use 80 distinct short historical names across eight balanced
  pools. Existing names and unknown saved contract fields are preserved.
- Untouched spawner presets retain opaque equipment/components through repeated
  reloads; explicit edits replace only the fields they own.

Runtime and matching loading-screen companion publish together. This Alpha does
not install to TEST or local clients. Licensed world/render/co-op acceptance and
the reported immediate wolf-flood reproduction remain TESTING.
