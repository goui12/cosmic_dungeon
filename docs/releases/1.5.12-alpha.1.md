# Cosmic Dungeon 1.5.12-alpha.1

Batch 9 adds Theurgist mercenary resurrection at **Positive Potions level 10**.
When a living, available Theurgist is in your group and instance, the death menu offers
**Accept Resurrection from <Name>**. Return to your exact death position with five seconds
of invincibility. The Theurgist then has a three-minute cooldown, shown in its inventory
group HUD tooltip after unlocking the skill. Normal death drops still apply.

The server rechecks the player, mercenary, run, death identity and cooldown; duplicate,
stale and forfeited-run requests cannot revive twice. Native respawn preserves class and
inventory/currency recovery behavior. A dead hirer may accept resurrection from their
own living Theurgist.

Client and server must both update: the party HUD network format advances to protocol 16.
Existing worlds need no manual migration. New per-run death/cooldown values start empty,
survive saves, and reset with the dungeon. Resurrection offers cover deaths recorded after
this update. Loading-screen companion ships at the same version.

Licensed multiplayer/death-screen QA remains pending. The next planned batch adds a Tamsin
lore/map replay "i" button and completes the set as **1.6.0-beta**.
