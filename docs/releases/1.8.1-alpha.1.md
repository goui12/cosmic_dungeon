# Cosmic Dungeon 1.8.1-alpha.1

Batch21 save/recovery hardening. Trade, shared crafting and resurrection reconciliation now distinguish absent partial-preparation proof from malformed present owner proof. Invalid tag types, unsupported receipt versions, foreign identities and malformed receipt shapes stay held with the field named in the review reason, before changing world outcomes, cursor/inventory or cooldown state. Supported old saves and valid unknown fields retain their original format; no schema migration or automatic deletion is introduced.

Automated recovery fixtures reload actual native owner files and install disk-decoded world journals at interruption/replay boundaries. They distinguish deterministic saved-state failure injection from actual process-crash testing; no user's game/server is killed or launched. Exact coverage/results belong to the Batch21 report/operational receipt after execution.

Retain complete world/player/account saves together. Unsupported/conflicting custody still requires complete-save review; do not guess ownership or discard evidence. No authored chest/loadout, registry ID, network payload, runtime dependency, heap or polling budget change. Alpha publication requires full clean/native/GameTests; no TEST or local-client delivery. Licensed gameplay journeys remain Cameron's manual work.
