# Cosmic Dungeon 1.6.3-alpha.1
- Blocked cosmic spawners emit sparse, faint red particles with normal wall occlusion instead of a solid through-wall outline.
- Trying to mine a cosmic spawner without a pickaxe shows "You need a pickaxe to break that!", throttled to once every two seconds.
- Player and mercenary Pyroclast fireworks destroy exposed, eligible cosmic spawners within five blocks. Ordinary terrain, walls and protected spawners remain intact; existing XP-bottle loot is retained.

Matching runtime and client-only loading-screen jars accompany this revision.
No saved-data, preset, registry or network format changes; no migration or datagen required.
Network protocol17 is unchanged from1.6.1-alpha.1/1.6.2-alpha.1. BOTH clients and server must update when upgrading from1.6.0-beta or older protocol16 builds.
Licensed visual and multiplayer acceptance remains pending.
