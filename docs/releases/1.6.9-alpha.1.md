# Cosmic Dungeon 1.6.9-alpha.1

- Add a movable inventory Skills panel with saved class layouts. Minimize keeps its
  title and resource display visible; reset its placement in Cosmic Dungeon Settings.
- Add equal-sized action rows, mouse-wheel scrolling and a draggable scrollbar.
- Open your exact class guide with the blue information button. Bogatyr and Theurgist
  include guide entries for their existing wolf-care and brewing mechanics.
- Coordinate Skills, group HUD and account placement. Keep group details scrollable
  in compact inventories and reserve the right-side region for Requests.
- Remove recipe-book buttons, book displays and ghost recipes across their menus.
  Existing crafting rules remain unchanged.

This is a testing Alpha. Resource balances are shown only when available.
Licensed GUI/multiplayer and CurseForge app acceptance remain pending.
Clients update through CurseForge; only TEST receives the direct sFTP update.
