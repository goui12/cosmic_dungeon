# D1 class ammunition and combat effects

Recognized D1 ammunition now enforces active-run ownership, class and attunement at
impact. Restorative arrows support teammates without ordinary arrow damage, including
teams with friendly fire disabled. Poison/regeneration retain native applicability,
and equal-strength effects no longer shorten longer existing effects.

Dragoon chain lightning requires an actual successful D1 trident hit. New server
CosmicDungeon.config candidate limits bound rocket and lightning obstruction work.
Existing balance values, vanilla equipment, authored payloads, save formats and
operator configs remain. No new texture is required.

effect cancellation, authored stacks and crowded-scene behavior still require licensed
TEST acceptance. This fragment does not mark the mod release-ready or deployed.
