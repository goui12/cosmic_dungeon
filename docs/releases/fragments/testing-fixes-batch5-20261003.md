# Group capacity, mobile readiness and HUD

- Leaders select maximum group size1–6 at Tamsin; a group can start below that maximum.
- Ready closes Tamsin. Members can move around the starting dimension; Not Ready
  preserves teammates' confirmations and cancels a pending start.
- Top-left group and invitation HUDs persist outside Tamsin. Inventory provides
  Ready/Not Ready, Leave Group and invitation Join Group controls. Recipe-book and
  currency placement keep slots accessible. Active dungeon rosters remain read-only.

Requires matching protocol9 client/server jars. Existing saved data needs no migration;
legacy minimumPartySize is retained for config compatibility and no longer imposes a minimum.
Licensed multiplayer/visual acceptance remains pending.
