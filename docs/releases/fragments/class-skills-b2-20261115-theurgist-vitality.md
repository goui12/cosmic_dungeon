# Theurgist max-health progression

Add a 45-minute max-health potion family shared by Theurgist players and mercenaries, with approved ranks from Scintilla Vitalis (+10%, level0) to Fulgor Vitae (+55%, level68). It never heals, only stronger ranks replace an active dose, and repeated equal/weaker applications cannot train support. The player crafts only the highest unlocked rank at standard Splash Healing costs; existing bottles survive.

Mercenary stock/use is restricted to Healing and max health. Positive potion bonuses begin at25; player positive recipes and resurrection remain available. Tooltips and dungeon unlock messages explain the current rank.

This is Batch2 of six, version1.8.10-beta.1, source-only until Batch6.
