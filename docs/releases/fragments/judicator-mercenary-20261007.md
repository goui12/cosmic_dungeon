# Judicator mercenary

Combat progression uses cumulative hostile kills1,3,6,12,24 then doubling, starting0.
Successful direct attacks have L% probability (maximum100%) of L HP damage to nearby
hostiles within2blocks. Allied entities are excluded and bursts do not recurse.
Run progress survives mercenary death/revival and resets for the next dungeon.
No authored class-chest, registry or existing save-field rewrites.
