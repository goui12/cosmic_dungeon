# Portable TEST client updates

A portable PS1/BAT pair in the CurseForge mods folder can fetch the confirmed TEST revision from the public test-builds branch. Updates compare SHA-256, including revisions with the same mod version, validate downloads, preserve other mods, and retain rollback backups. Minecraft must be closed for replacement.

Successful wrapper builds publish latest-built; completed verified TEST deployments publish current-test for testers. No gameplay or saved-data change.
