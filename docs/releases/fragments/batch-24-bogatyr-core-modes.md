# Cosmic Dungeon 1.6.14-alpha.1

- Bogatyr Wolfpack gains free Defensive, Stand Ground and Aggressive modes with one selected border.
- Defensive protects you and responds to attacks on your pack. Aggressive attacks nearby hostiles nearest you first.
- Stand Ground immediately stops and sits the pack, including under attack. Select another mode to resume movement; Breed is unavailable while holding ground.
- Mode selection survives normal run saves and reconnects, applies to unloaded wolves on return, and stays separate for each owner and dungeon run.
- Target scans and heavy path updates are bounded and staggered. Friendly players, pets and NPCs remain protected; packs remain uncapped.
- Strategic, Search and Rescue, and Danger Close remain unavailable for the next batch.

Set C Alpha. Licensed visual/co-op/pathfinding acceptance remains TESTING. Install the matching runtime/loading companion through CurseForge; TEST delivery uses stopped-server sFTP.
