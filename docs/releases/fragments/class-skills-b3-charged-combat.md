# 1.8.11-beta.1 — Charged class combat

Unpublished source beta, Batch3 of6. Development source and GitHub only; distribution is held until the completed official Batch6 build.

- Dragoon players and mercenaries charge Chain Lightning with100 effective hostile trident hits. Players arm with the remappable primary key (defaultG); mercenaries arm automatically. The next valid trident strike releases it.
- Judicator Smite replaces random mercenary bursts. Ten undead kills charge an undead-only area attack, with four ranks earned by successful activations. An ineffective cast preserves charge and explains why.
- Inventory primary actions show charge and current skill; run-owned bars preserve class/lifecycle boundaries and exclude secondary self-charging.
- Existing allies, resurrection, authored equipment and legacy progression history remain protected.
