# Batch 8 — mercenary hiring and entry

- Group members can reserve or release one mercenary through Tamsin. Each uses one of the group's maximum six slots. Dungeon 1's existing class availability applies.
- The default fee is 500 Trace, independently configurable through mercenaries.hireTrace. A hire keeps its quoted price; successful startup charges each hirer once. Cancelled or interrupted entry releases the account reservation.
- Mercenaries receive distinct starter slots and personal chest ownership. Their actual authored equipment and supplies transfer intact, with no loadout generation or component rewriting. Other players' bound items are rejected.
- Run contracts, account receipts, entity equipment and supplies persist. Old saves default to no mercenaries/fees. Network protocol 11 requires matching client and server builds.
- This is the entry/equipment foundation. Follow/combat/brewing are Batch 9; the stacked health HUD and equipment-preserving death/respawn are Batch 10. Licensed gameplay acceptance remains pending.
