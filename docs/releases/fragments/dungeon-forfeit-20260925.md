# Dungeon forfeit voting

Dungeon entry now explains /ff. Members can open a 60-second Yes/No vote;
at least two-thirds of the run roster must explicitly agree, rounded up.
Passing fails only that instance, forfeits dungeon loot, and uses existing
saved outside-inventory recovery, including offline-player recovery.
Solo runs require an explicit Yes confirmation. Duplicate votes and stale buttons
cannot count twice; disconnecting does not reduce the threshold.

No saved-data migration or datagen is required. Native multiplayer acceptance is pending.
