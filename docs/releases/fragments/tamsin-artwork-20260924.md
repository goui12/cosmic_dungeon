# Tamsin's custom appearance

- Bound villager Tamsin now wears Cameron's custom body and clothing textures.
- Normal villagers keep their own textures; a matching name alone does not select the artwork.
- Tamsin's appearance returns automatically on world load and clears when unbound.
- Her custom outfit replaces biome, profession and trade-badge overlays.
- Clients and servers must use the matching updated mod. Existing bindings and saves need no migration.
