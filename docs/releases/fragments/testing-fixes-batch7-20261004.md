# Persistent class weapon skills

Weapon skills now progress separately for each class and survive death, forfeit and
switching classes. Active adventure members earn XP from actual weapon finishing blows;
companion and environmental finishing damage cannot train the held weapon.
Server-configurable level curves and damage/class bonuses follow the offline class mappings.
Theurgist potions train through effective healing, new/improved useful buffs and direct
potion kills, with per-recipient cooldowns and a shared action cap. Empty throws,
overhealing and equal-buff refreshes do not train skills. Support arrows train their bow.
Use the existing /progression get <player> command to inspect current-class levels and XP.
