# Dungeon 1: The Tamsin Tax

Returning players can settle Tamsin's promised cut after personally reaching Base Camp
and subsequently completing D1 successfully. The menu lists carried approved loot,
asks for confirmation, then removes one item without currency payment or shop stock.
A player-save receipt allows achievement recovery after reconnect without consuming again.

Adds developer Base Camp binding, three Tamsin server settings and a hidden name-only
achievement. Matching protocol-5 client/server jars are required. Existing authored items
are preserved; trusted named identities remain required. No new item PNG is needed.

Implemented in code; licensed TEST binding, menu, multiplayer and save/restart acceptance
remain pending. Not deployed. Other currency/trade/repair recovery work is still tracked.
