# D1 death currency

Confirmed deaths apply configurable canonical Trace loss and create one recoverable logical drop.
Any player with room for the whole amount can collect it directly into their account.
Native item aging, damage and expiry remain; drops cannot enter inventories, automation or merges.
Debit/drop/pickup/destruction evidence shares the account save, with bounded recovery and active-drop supply reporting.
Dimension reset accounts for loaded and unloaded drops before deletion.

Optional account/player fields preserve old saves; no registry, protocol or spawner format change.
Java 21 build, 2,549 offline checks and two config round trips passed.
Licensed native/multiplayer acceptance remains pending; this fragment is not deployment approval.
