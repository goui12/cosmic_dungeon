# Tamsin group recruitment and class selection

- Create a named group at Tamsin; members can leave and leaders can disband.
- Advertise your selected class through Looking for Group. Every group member can
  invite an advertised player or an online friend who is not advertising.
- Select and change classes through Tamsin. The selector block points players to her;
  active runs still prevent class changes and late joins.
- Invitations are tied to the original group and expire safely after departures/disbanding.

Requires matching client/server builds (network protocol 8). No saved-world migration.
Gameplay acceptance remains pending; mobile ready/group/invitation HUDs follow in batch 5.
