# Batch19 - reusable inventory Skills foundation

Movable, persistent per-class Skills panel with minimizing, uniform action rows,
wheel/visible scrollbar and exact class H-guide shortcut. Shared inventory geometry
coordinates group/account panels and reserves Requests. Cosmic Dungeon Settings
includes Reset Skill Panel UI; recipe-book surfaces are removed client-side.
Gameplay permissions, authored chests and world schemas remain unchanged.
