# Cosmic Dungeon 1.8.6-alpha.1

First Alpha milestone for FixSet F1/F2, Minecraft 1.21.10 / NeoForge.

- Class inventory artwork and Bogatyr controls request authoritative class data after dimension travel/respawn.
- Theurgist and Venefex always show a scrollable opaque potion list; each legal normal/strong/extended variant is separately labeled. Pre-game recipes are disabled previews.
- Potion-list item drags respect inventory bounds; compact active-effect icons and overflow details stay visible above Resurrect.
- The enabled Ready action is green with a restrained two-second pulse. Hover/focus, native narration and server-confirmed Ready/Not Ready behavior are preserved.
- Explicit YES/NO resource choices freeze at accepted Start Adventure, including queue/countdown, and stay fixed for the run. Pre-game choice controls return after completion/forfeit or canceled entry.
- Active party information stays readable. Every shared craft still revalidates current membership, online/living state, run/dimension and transaction eligibility.

No save migration or new runtime dependency. Existing saved choices and unknown values are retained; missing/unknown values never opt players in. Runtime and matching loading-screen companion publish together. This Alpha does not install to TEST or local clients. Licensed GUI/co-op acceptance remains TESTING.
