# Cosmic Dungeon 1.6.6-beta.1

This Beta closes Set A of the October party/combat reliability work. It includes trade/readiness safety,
player-wolf friendly-fire protection, wall-occluded Cosmic Spawner feedback and Pyroclast spawner breaks,
the complete party health/effect HUD, current-run human member inspection, and latest-death inventory
organization.

Batch16 records the latest real D1 death's slot layout without taking custody of any item. Only amounts
actually picked up from current-death physical drops may be moved toward their original slots. New contents
are never overwritten; missing, destroyed, stolen and old-death items are never recreated or reclaimed.
Physical death-drop provenance prevents unrelated or different-death entities from silently merging.

The layout is an additive bounded value in the existing D1 run store. Old saves default to no layout and
run retirement removes it. No new registry, spawner/preset, currency or network schema is introduced;
protocol19 remains the matching client/server protocol from Batch15. Datagen is not applicable.

The Beta is publishable only from the validated merged-main Set A source after clean build/native GameTests,
review and release provenance checks pass. Licensed multiplayer/UI acceptance and CurseForge companion-app
delivery remain separate acceptance gates before stable.
